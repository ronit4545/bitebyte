\# 🍴 BiteByte



\*\*BiteByte\*\* is an online recipe-sharing platform where users can discover recipes, share their own creations, rate dishes, and leave comments.



\## ✨ Features



\* 👤 User registration and login

\* 🍲 Browse and discover recipes

\* 📝 Share and manage recipes

\* ⭐ Rate recipes and leave comments

\* 🛡️ Admin dashboard for managing users and recipes

\* ✅ Admin approval or rejection of submitted recipes



\## 🛠️ Technologies Used



\* \*\*Frontend:\*\* HTML, CSS, JavaScript

\* \*\*Backend:\*\* Java

\* \*\*Build Tool:\*\* Maven

\## 🚀 Getting Started



\### Prerequisites



\* Java JDK

\* Apache Maven

\* A modern web browser

\* Your project's configured database, if required



\### Run the Backend



Open PowerShell in the Java backend directory and run:



```powershell

mvn spring-boot:run

```



\*This command applies only if your backend is configured with Spring Boot. Otherwise, use the startup command appropriate to your Java application.\*



\### Run the Frontend



Open the frontend folder in VS Code and run it using the development command configured in its `package.json`, or use the appropriate static web server if it is a plain HTML/CSS/JavaScript project.



\## 🎯 Project Objective



BiteByte aims to make sharing and discovering recipes easy while providing administrators with tools to manage users, recipe submissions, and platform content.
